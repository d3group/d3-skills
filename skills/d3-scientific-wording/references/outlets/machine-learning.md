# Outlet family: Machine learning

Read this together with `../outlets.md` (detection, genre profile, reader, term sheet). Limits of pages, words and highlights differ between venues and change over time: take them from the call or the guide to authors. A measured outlet profile (`../profiles.md`) beats this file wherever both exist.

- The introduction ends with an enumerated list of contributions, each a concrete claim: "We derive a regret bound of ...", "We show on four benchmarks that ...".
- Every empirical claim carries its setting: data sets, baselines, metric, seeds or confidence intervals. "State-of-the-art" only with the benchmark and the compared methods.
- Theory in theorem-proof register: "Under Assumptions 1 and 2, ...". "Prove" is reserved for proofs; "show" for experiments.
- Numeric or author-year citations as the style file sets them.
- Double-blind: the group's own earlier work in the third person ("Smith et al. [12] show"), no identifying links or acknowledgements.
- A limitations paragraph is expected; write it plainly, with the mechanism.
