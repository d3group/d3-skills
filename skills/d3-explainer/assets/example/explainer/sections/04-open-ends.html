What is assumed, what is open, and the notation

Three places where paper, code and results do not say the same thing, one assumption everything rests on, and one open end.

Paper and code answer different questions The paper reports the limit, $x^\star = 1/\e$ with a success probability of 0.368 [[paper:eq:limit]]. The code enumerates the exact optimum for the given $n$ [[code:src/secretary.py:15 def optimal_cutoff]], which gives 0.384 at $n = 20$. Both are right: the finite-$n$ value lies above the limit and falls to it. The simulation section of the paper does not say which of the two its numbers should be compared with. [[paper:sec:sim]]
The code covers a case the paper excludes The paper states the success probability for $r \ge 2$ only [[paper:eq:prob]]. The code returns $1/n$ for $r \le 1$ [[code:src/secretary.py:8 def success_probability]], which is correct (take the first candidate), is stored in the results file, and is drawn as the leftmost point of {fig:fig-results}.
Paper and result file disagree For $n = 100$ the results grid moves in steps of five cutoffs, so the best cutoff on the grid is 35 skipped, while the same file stores optimal_r = 38, that is 37 skipped [[result:results/success.json]]. The file is also a single seeded run [[code:src/secretary.py:34 default_rng(7)]], so the agreement in that figure is one draw, not a distribution. A reader of {fig:fig-results} could take the grid maximum for the optimum.
Open question The gap table in section 01 lists payoffs beyond "best or nothing" as planned. Nothing in the code supports a payoff by rank yet, and the single-cutoff derivation above does not carry over to it.
Why the first step needs the random arrival order optional depth

Given that the best candidate stands at position $k$, the first $k-1$ candidates are a uniformly random subset in uniformly random order. The best of them is therefore equally likely to stand at any of the $k-1$ positions, and it stands among the first $r-1$ with probability $(r-1)/(k-1)$. With a trend in quality over time this symmetry fails, and the success probability of the paper with it. [[paper:eq:prob]]
